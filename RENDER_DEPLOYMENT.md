# Deploying Varuna Netra on Render

This guide outlines how to deploy **Varuna Netra** (Oil-Spill Detection & Vessel Correlation Platform) to [Render](https://render.com).

---

## Architecture Overview

- **Backend**: FastAPI (Python 3.11) Web Service with Uvicorn, background workers, and AIS stream listeners.
- **Frontend**: React 19 Single Page Application (Static Site on Render with CDN & rewrite rules).
- **Database**: MongoDB (e.g., MongoDB Atlas Free/Dedicated Tier or Render MongoDB).

---

## Method 1: 1-Click Blueprint Deployment (Recommended)

Render Blueprints let you deploy both services together using the [`render.yaml`](./render.yaml) file in this repository.

### Prerequisites
1. A [Render Account](https://dashboard.render.com).
2. A free [MongoDB Atlas](https://www.mongodb.com/atlas) cluster (or any hosted MongoDB instance).
3. The Varuna Netra repository pushed to your GitHub or GitLab account.

### Step-by-Step Deployment
1. Log in to the [Render Dashboard](https://dashboard.render.com).
2. Click **New +** and select **Blueprint**.
3. Connect your repository containing Varuna Netra.
4. Render will automatically detect [`render.yaml`](./render.yaml) and declare two services:
   - `varuna-netra-backend` (Web Service)
   - `varuna-netra-frontend` (Static Site)
5. Under the environment variables prompt:
   - Provide your **`MONGO_URL`**: e.g., `mongodb+srv://<username>:<password>@cluster0.mongodb.net/?retryWrites=true&w=majority`
   - `DB_NAME`: `varuna_netra` (or `sentinelmar`)
   - `JWT_SECRET`: auto-generated by Render.
6. Click **Apply**.
7. Once the backend builds and deploys, note its URL (e.g., `https://varuna-netra-backend.onrender.com`).
8. In the Render Dashboard for `varuna-netra-frontend`:
   - Set **`REACT_APP_BACKEND_URL`** to your backend URL (`https://varuna-netra-backend.onrender.com`).
   - Trigger a redeploy of the frontend so the backend URL is baked into the React build.
9. In the Render Dashboard for `varuna-netra-backend`:
   - Set **`FRONTEND_URL`** and **`CORS_ORIGINS`** to your frontend URL (`https://varuna-netra-frontend.onrender.com`).

## Method 2: Manual Service Creation

If you prefer to configure services manually in the Render Dashboard:

### 1. Deploy the Backend (Web Service)
- **Type**: Web Service
- **Name**: `varuna-netra-backend`
- **Root Directory**: `backend`
- **Runtime**: Python 3
- **Build Command**:
  ```bash
  pip install --upgrade pip && pip install -r requirements.txt
  ```
- **Start Command**:
  ```bash
  uvicorn server:app --host 0.0.0.0 --port $PORT
  ```
- **Health Check Path**: `/api/health`
- **Environment Variables**:
  | Variable | Value / Description | Required |
  |---|---|---|
  | `PYTHON_VERSION` | `3.11.9` | Yes |
  | `MONGO_URL` | `mongodb+srv://<user>:<pass>@cluster.mongodb.net/...` | Yes |
  | `DB_NAME` | `varuna_netra` | Yes |
  | `JWT_SECRET` | 32+ character random secret | Yes |
  | `APP_ENV` | `production` | Yes |
  | `DEMO_MODE` | `false` | Yes |
  | `CORS_ORIGINS` | `https://varuna-netra-frontend.onrender.com` | Yes |
  | `FRONTEND_URL` | `https://varuna-netra-frontend.onrender.com` | Yes |
  | `AISSTREAM_API_KEY` | *(Your AISStream key for live AIS data)* | Optional |
  | `OPENAI_API_KEY` | *(Your OpenAI key for AI Case Assistant)* | Optional |

### 2. Deploy the Frontend (Static Site)
- **Type**: Static Site
- **Name**: `varuna-netra-frontend`
- **Root Directory**: `frontend`
- **Build Command**:
  ```bash
  yarn install && yarn build
  ```
- **Publish Directory**: `./build`
- **Environment Variables**:
  | Variable | Value | Required |
  |---|---|---|
  | `NODE_VERSION` | `20.18.0` | Yes |
  | `REACT_APP_BACKEND_URL` | `https://varuna-netra-backend.onrender.com` | Yes |
- **Redirects & Rewrites**:
  - **Type**: Rewrite
  - **Source**: `/*`
  - **Destination**: `/index.html`
  *(Essential for client-side routing with React Router).*

## Post-Deployment Verification

1. **Backend Health Check**:
   Visit `https://<your-backend>.onrender.com/api/health`
   Expected response:
   ```json
   {
     "status": "ok",
     "ready": true,
     "environment": "production",
     "database": "online",
     ...
   }
   ```

2. **Frontend UI**:
   Visit `https://<your-frontend>.onrender.com`
   - Test "Explore as Guest" (read-only mode).
   - Test user registration and login.
   - Verify that data loads without CORS errors in the browser developer console.

## Useful Tips & Troubleshooting

- **CORS Errors**: Ensure `CORS_ORIGINS` on the backend exactly matches the frontend URL including the protocol (e.g. `https://varuna-netra-frontend.onrender.com`) without a trailing slash. By default, any `*.onrender.com` origin is allowed.
- **SPA 404 on Refresh**: Ensure the rewrite rule `/* -> /index.html` is added under the Static Site's "Redirects/Rewrites" tab in Render.
- **MongoDB Atlas IP Whitelist**: Remember to add `0.0.0.0/0` (allow access from anywhere) in your MongoDB Atlas Network Access settings so Render instances can connect.
- **Local File Uploads**: File attachments are stored in `backend/.uploads`. For persistence across Render restarts/ephemeral dynos, attach a Render Persistent Disk mounted to `/app/.uploads` or configure `INTEGRATION_PROXY_URL`.
