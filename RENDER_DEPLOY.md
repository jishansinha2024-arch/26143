# Varuna Netra - Render deployment

This version intentionally uses **two ordinary Render Web Services** instead of a `runtime: static` frontend. This avoids the `unknown type "static"` Blueprint validation error shown by some Render Blueprint flows.

## Services
- `varuna-netra-api`: FastAPI backend, Python runtime.
- `varuna-netra-web`: React frontend, Node runtime serving the production `build/` folder with `frontend/server.js`.

## Blueprint
The root `render.yaml` is ready for Render Blueprints.

## Required secrets
Set these in the Render Blueprint/service setup:
- `MONGO_URL`
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `AISSTREAM_API_KEY`
- `OPENAI_API_KEY` (optional)

`JWT_SECRET` is generated by Render.

## AISStream
Only the production backend has `AIS_INGEST_ENABLED=true`. Do not run another backend/preview instance with the same AISStream key at the same time, or AISStream may return HTTP 429 concurrent-connection errors.
